# 魔方复原教练 · Rubik Solver

纯前端三阶魔方求解与教学网页应用。零依赖、零构建，打开即用。

**在线使用**：<https://x-lsh.github.io/rubik-solver/>

![技术栈](https://img.shields.io/badge/tech-vanilla%20JS%20%2B%20CSS%203D-blue)

## 功能

- **3D 可视化魔方**：纯 CSS 3D 渲染，trackball 全向视角（任意方向 360° 翻滚），转动动画与状态实时联动
- **一键随机打乱**：22 步标准打乱，动画逐步呈现
- **手动编辑状态**：展开图点击涂色（画笔模式 / 循环换色），自动校验状态合法性
  （颜色计数 / 角块扭转和 / 棱块翻转和 / 排列奇偶性；区分「数量错误」与「数量正常但不可复原
  （角扭转 / 棱翻转 / 两块互换）」两类非法状态并给出具体原因）
- **拍照录入状态**：摄像头逐面拍摄真实魔方，自动识别六面颜色生成可求解状态
  - 面归属由每面中心块颜色自动判断，照片的面内旋转自动搜索校正
  - 九宫格取景框实时采样预览 + 单格参考分类，拍摄前即可发现可疑格
  - 识别异常时自动在展开图上以黄框标记最可疑的格子，引导手动修正
  - 摄像头不可用 / 权限被拒时自动降级为「上传图片」识别，同一流程
- **两种求解算法**：
  - **层先法 LBL**：十字 → 底角 → 中层棱 → 顶面 OLL → 顶层 PLL，平均 ~116 步
  - **CFOP**：Cross → F2L（逐槽位）→ OLL → PLL，平均 ~109 步
- **分步演示**：阶段分组卡片、当前步高亮、播放/暂停/单步/回退/跳转、速度调节
- **响应式**：桌面双栏 / 移动端单列，支持触屏拖拽

## 拍照录入使用说明

1. 打开「拍照录入」标签，点击「启动摄像头」（浏览器会请求摄像头权限）
2. 将魔方任意一面正对取景框（九宫格对准 3×3 贴纸），确认色卡识别合理后点「拍摄本面」
3. 依次拍摄六个不同的面（顺序随意，归属自动判断）；拍错可点击下方缩略图重拍
4. 六面拍齐后点「应用 54 格状态到魔方」：
   - 识别成功 → 自动切换到 3D 魔方，直接求解
   - 存在识别错误 → 展开图黄框闪烁最可疑的格子，对照真实魔方修正后再求解

> **摄像头要求**：浏览器仅在 **HTTPS** 或 `localhost` 下允许访问摄像头。
> GitHub Pages 在线版可直接使用；本地双击 `file://` 打开时请改用「上传图片」路径，
> 或用 `python -m http.server` 本地起服务后访问 `http://localhost:8000`。
>
> **拍摄建议**：均匀光线、避免直射反光；让贴纸面正对镜头充满取景框；
> 识别结果若个别格有误，黄框标记 + 手动修正兜底。

## 求解引擎原理

`js/cube-engine.js`
- 54 贴纸（facelet）状态模型；18 种转动的置换表由 3D 坐标系自动生成（x 右 / y 上 / z 前，WCA 顺时针约定），杜绝手写置换错误
- 状态合法性校验：中心互异 + 每色 9 张 + 角/棱块双射 + 角朝向和 ≡ 0 (mod 3) + 棱朝向和 ≡ 0 (mod 2) + 角棱排列奇偶一致

`js/color-scan.js`（拍照识别核心）
- 每格取中心 30% 区域 RGB 通道中位数（抗反光 / 边缘干扰）→ sRGB→Lab(D65) 感知均匀色差
- 6 中心色线性域增益白平衡校正（暖光 / 冷光 / 暗光偏移）；中心块标定：类别参考点用实测中心色
- 48 格 ΔE 最近邻 + 「每色恰 9」平衡贪心分配；中心色 6! 全排列最优匹配确定颜色标签
- 组装：面归属由中心色决定 + 4^6 面内旋转枚举搜索（计数预筛 + validate），自动校正照片朝向；
  每格 margin（分类区分度）用于定位识别错误的可疑格

`js/solver.js`
- **前三层**：每个目标块在「位置×朝向」24 态子状态图上 BFS；生成元 = 单步转动 + 净保持先验的宏观序列（共轭提取宏 `X U^k X'`、翻棱宏、sexy move 插入、中层插入公式），每个生成元经置换合成动态验证"不破坏已完成块"
- **顶层**：2-look OLL/PLL 经典公式（翻棱、Sune/反 Sune、T-perm、U-perm）先验证置换性质，再在顶层面/排列状态空间上 BFS 出最短生成元序列；角棱排列因 U 转动耦合，采用联合 PLL 状态空间（24×24）一次求解
- 随机 100 例测试全部复原（`node test/test-solver.js`）

## 运行

直接双击 `index.html`（拍照功能需 HTTPS / localhost），或：

```bash
cd rubik-solver
python -m http.server 8000
# 打开 http://localhost:8000
```

## 测试

```bash
node test/test-engine.js      # 引擎：置换双射/逆序复原/合法性校验
node test/test-solver.js      # 求解器：100 例随机状态 LBL + 50 例 CFOP
node test/test-color-scan.js  # 颜色采样与组装：白平衡/噪声/反光/旋转搜索/可疑格定位
node test/e2e-orbit.js        # E2E：trackball 全向视角
node test/e2e-scan.js         # E2E：拍照录入全链路（假摄像头/降级/上传）
node test/browser-test.js     # E2E：打乱→求解→播放→复原 主流程
node test/mobile-test.js      # E2E：移动端视口
```

浏览器 E2E 依赖 `test/.pwtest/` 内的 playwright-core 与系统 Edge，见脚本头部注释。

## 文件结构

```

├── index.html          # 页面入口
├── css/style.css       # 深色现代风格样式

│   └── app.js          # 界面逻辑（编辑器/播放器）
└── test/               # Node 单元测试 + Playwright E2E
```
